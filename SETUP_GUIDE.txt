## 💻 2. Naye Laptop Par Project Kaise Setup Karein (Hinglish Guide)

Naye laptop par file extract karne ke baad, yeh steps sequential follow karein:

### Step 1: Token Server Ko Start Karein (Agora Video Call Token Service)
Agora token generate karne ke liye Node server chalana padega.
1. `token_server` folder ko Command Prompt / Terminal me open karein:
   ```bash
   cd token_server
   ```
2. Node packages install karein:
   ```bash
   npm install
   ```
3. Server ko start karein:
   ```bash
   npm start
   ```
   *(Yeh server `http://localhost:3000` par start ho jayega. Ise chalu chhod do and minimize kar do).*

---

### Step 2: Naya Firebase Project Kaise Connect Karein (Agar setup karna pade)
Agar interview me aapko naya Firebase account link karne ko bole ya aap naye database rules setup karna chahein:

1. **Firebase Web Console** open karein: [console.firebase.google.com](https://console.firebase.google.com/)
2. **Add Project** par click karke naya project banayein: `wtf-guru-trainer-test`.
3. Left-side sidebar me **Firestore Database** par click karein -> **Create Database** par click karein:
   - Location: Default select rehne dein.
   - Rules: ⚠️ **Start in Test Mode** select karein (rules public ho jayenge aur authentication error nahi aayegi).
4. Project overview me **Add App (Android robot icon)** par click karein:
   - **Guru App** registration:
     * Android package name: `com.wtf.guru`
     * Nickname: `Guru App`
     * Register karke `google-services.json` file download karein.
   - **Trainer App** registration:
     * Android package name: `com.wtf.trainer`
     * Nickname: `Trainer App`
     * Register karke `google-services.json` file download karein.

5. **Files ko projects me copy karein**:
   - Guru App waali file copy karein:
     `wtf_flutter_test-main/guru_app/android/app/google-services.json`
   - Trainer App waali file copy karein:
     `wtf_flutter_test-main/trainer_app/android/app/google-services.json`

*(Note: Humne already setup kar rakha hai, toh agar aap setup change nahi karna chahte, toh purane files se hi run ho jayega, direct run step par chalein).*

---

### Step 3: Dependencies Sync Karein
Android Studio me projects kholne ke baad dono windows me niche `Terminal` tab par click karein aur command chalayein:

1. **Shared Package** me:
   ```bash
   cd shared
   flutter pub get
   ```
2. **Guru App** me:
   ```bash
   cd guru_app
   flutter pub get
   ```
3. **Trainer App** me:
   ```bash
   cd trainer_app
   flutter pub get
   ```

---

### Step 4: Run Both Apps (Side-by-Side)
1. Ek Android Emulator ya Device laptop se connect karein.
2. Android Studio me `guru_app` select karke **Green Play button (Run)** par click karein.
3. Phir Android Studio me `trainer_app` select karke dubara **Green Play button (Run)** click karein.
4. Dono apps install ho jayengi. 

---

## 🧪 3. Demo Flow kaise dikhana hai (Reviewer Walkthrough):
1. **Trainer App (Red)** open karein -> Any password/email daal kar Aarav trainer profile login karein (mock validation). Back screen par open chhod dein.
2. **Guru App (Blue)** open karein -> DK user select karke trainer list me Aarav select karke onboarding complete karein.
3. **Chat**: Guru app se message likhein, Trainer app par live real-time sync notification aur reply.
4. **Call Booking**: Guru app se booking slot request send karein, Trainer app par approve karein.
5. **Video Call**: Dono apps me call screen active hogi, Join call click karke camera/mic permission pass karein aur call test karein!
